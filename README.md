# LG Display-Prototypes

Interactive prototypes built from a Figma design file.

| Path | What it is |
|---|---|
| `/` | Landing page linking both prototypes |
| `/app/` | **Phone app prototype** from the Figma *Design* page — 136 screens, ~390 tap areas |
| `/presentation/` | Pitch deck from the *발표자료* page with its click-through flow |

## App prototype
- Pick a flow on the left (User: sign-up, home, registration, ONE PASS, community, my page · Admin: add event, access control, admin hub).
- Tap buttons on the phone like a real app. Tap an empty spot to flash the tap areas, or turn on **Show tap areas**.
- Keys: `←` back · `R` restart · `H` toggle tap areas. Link straight to a screen with `#<frame-id>`, e.g. `app/#1352-6562` (Home).
- On a phone, the app fills the screen and the flow menu sits behind the ☰ button.

## Presentation
Click / → / Enter to advance, ← to go back, `F` for fullscreen.

## Publish on GitHub Pages
1. Push this folder to a GitHub repo.
2. Repo **Settings → Pages → Deploy from a branch → `main` / root**.
3. Open `https://<username>.github.io/<repo>/`.
