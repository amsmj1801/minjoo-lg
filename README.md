# CLUB X — Presentation Prototype

A clickable web version of the Figma prototype on the **발표자료** page of *CLUB.LMS UI*.

**Controls:** Click / tap / → / Enter / Space to advance · ← to go back · swipe on mobile · `F` for fullscreen.
Jump to a slide with `#N` in the URL (e.g. `index.html#18`). On slide 18 (06_After), tap the phones to switch screens.

## Publish on GitHub Pages
1. Push this folder to a GitHub repo.
2. Repo **Settings → Pages → Deploy from a branch → `main` / root**.
3. Open `https://<username>.github.io/<repo>/`.
